# ライトノベル・プロット検討デモ

「異世界へ転移したヨーヨー世界王者が、糸魔法と競技技術で無双する」という架空のライトノベル企画です。主人公とヒロインのキャラクターシート、魔法ルール、全5章のプロットを一つのキャンバスで参照できます。

## アプリで開く（v0.6.0）

1. 上部バーの `設定` → `画像生成` タブを開き、`画像保存先ディレクトリ` にこのリポジトリの `manuals/demo` ディレクトリを指定して `保存` します。
2. 上部バーの `開く` から `light-novel-plot-ja.canvas.json` を選択します。
3. 画面右上のズーム率ボタンをクリックして全体を表示（`fitView`）します。
