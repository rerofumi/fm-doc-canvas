# README スクリーンショット用デモ

日本のソフトウェア開発チームが「障害対応ナレッジ基盤」を設計レビューしている想定のデモデータです。プロダクト概要、提案アーキテクチャ、段階リリース、レビュー論点、ADR、次のアクションを有向エッジで接続しています。

## アプリで開く（v0.6.0）

1. 上部バーの `設定` → `画像生成` タブを開き、`画像保存先ディレクトリ` にこのリポジトリの `manuals/demo` ディレクトリを指定して `保存` します。
2. 上部バーの `開く` から `product-planning-ja.canvas.json` を選択します。
3. 画面右上のズーム率ボタンをクリックして全体を表示（`fitView`）します。

図版の編集元は `architecture.svg` と `release-flow.svg`、アプリで表示する画像は同名の PNG です。
