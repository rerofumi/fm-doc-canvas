# FM Doc Canvas Reference Manual

[日本語](reference.md) | [English](reference_en.md)

This document is an operational reference for the features available through the FM Doc Canvas GUI. It is based on the Japanese-language GUI and implementation as of August 19, 2026.

> **Terminology:** Names such as `Canvas`, `Relation`, `SubCanvas`, `Chat`, and `Direct` appear in English in the application. This manual uses the same GUI terminology.

## 1. Purpose of the Application

FM Doc Canvas is a desktop application for placing text, Markdown artifacts, and images on an infinite Canvas and organizing ideas and source material by connecting them with Relations. You can also use LLMs, image generation, and web search to summarize, compare, and develop the information on the Canvas.

The Canvas serves as a temporary workbench. Finished text, images, and slide sources can be exported individually.

## 2. Interface

### 2.1 Top Toolbar

|Item|Action|
|---|---|
|`Text`|Adds an empty Text node.|
|`Artifact`|Adds an empty Artifact node.|
|`Undo`|Undoes the most recent Canvas operation.|
|`Auto Layout`|Automatically arranges nodes on the current Canvas.|
|`AI Assistant`|Opens or closes the AI Assistant on the right side.|
|`Settings`|Opens the Settings drawer on the right side.|

### 2.2 Breadcrumbs

Your current location appears below the toolbar in the form `Workspace > SubCanvas name`.

- `Parent`: Returns to the Canvas one level above. It is disabled directly under the Workspace.
- Canvas name: Navigates to the selected level.
- The number of cross-boundary Relations is also shown when any exist.

### 2.3 Main Canvas

This is the workspace where you place, select, move, and connect nodes.

- Drag an empty area: Pan the Canvas.
- Mouse wheel: Zoom in or out.
- `+` / `-` in the lower-left corner: Zoom in or out.
- Fit View in the lower-left corner: Adjust the view to show all nodes.
- Lock in the lower-left corner: Enable or disable Canvas interaction.
- Mini Map in the lower-right corner: Show your current position within the entire Canvas.

### 2.4 Node Editor

The Node Editor appears on the left when a Text or Artifact node is selected. Close it with `×`.

|Item|Action|
|---|---|
|`Edit`|Edits the Markdown source. Changes are reflected in the node immediately.|
|`Preview`|Shows the rendered Markdown.|
|`Convert to Artifact` / `Convert to Text`|Converts between the Text and Artifact roles.|
|Filename|The filename used when exporting an Artifact.|
|`Summary`|A short description shown on the node. It can be edited directly.|
|`Regenerate`|Regenerates the summary with an LLM. LLM configuration is required.|

You can also double-click a Text or Artifact node to open the editor.

### 2.5 AI Assistant

Click `AI Assistant` to show it on the right. Drag its left edge to resize it. See “7. AI Assistant” for details.

### 2.6 Settings Drawer

Click `Settings` to show it on the right. It contains LLM, image-generation, web-search, save, and load settings. See “10. Settings” for details.

## 3. Node Types

### 3.1 Text

Markdown text for notes, AI responses, and work-in-progress research. It can be converted to and from Artifact.

### 3.2 Artifact

Text intended to be completed as a file and exported as Markdown. Like Text, it supports Markdown editing and preview.

### 3.3 Image

An image imported from a file or generated by AI.

- Double-click: Enlarges the image.
- Generated images retain information such as the generation prompt, provider, and model.
- Image nodes can be selected as context for Chat or Direct. Configure a model that supports image input.

### 3.4 FolderNode

A node representing the entry point to a SubCanvas. Double-click it to enter that SubCanvas.

## 4. Selection and Basic Operations

### 4.1 Selecting Nodes

- Click: Select one node.
- `Ctrl`, `Command`, or `Shift` + click: Select multiple nodes.
- Click an empty area: Clear the selection and close the Node Editor.

Multiple selection is used for comparisons, Relation creation, SubCanvas creation, Marp export, and other operations.

### 4.2 Moving Nodes

Drag a node to move it anywhere. Use `Auto Layout` to arrange the current Canvas automatically.

### 4.3 Quick Relation Creation

Drag from one node's connection handle to another node's handle to create a Relation. To specify a type, reason, and direction, use `Add Relation` in the context menu.

### 4.4 Undo

`Undo` reverses the most recent node or Relation creation, edit, deletion, Direct Transform, SubCanvas conversion, or similar operation. A dedicated `Undo` action may also appear in an AI operation completion notification.

## 5. Context Menus

Available items vary depending on where you right-click, the node type, the number of selected nodes, and the current Canvas level.

### 5.1 Right-clicking a Node

|Item|Action / condition|
|---|---|
|`Create SubCanvas`|Moves selected nodes into a new SubCanvas and creates a FolderNode on the current Canvas.|
|`Move Selected Nodes to Parent Canvas`|Moves selected nodes in a SubCanvas one level up.|
|`Rename SubCanvas`|Renames the SubCanvas represented by a FolderNode.|
|`Delete SubCanvas`|Removes the SubCanvas. Members return to the parent Canvas, and Relations among members are preserved.|
|`Summarize`|Uses an LLM to summarize the selection and creates a derived Text node.|
|`Compare`|Compares multiple selected nodes and creates a derived Text node.|
|`Counterargument`|Generates a counterargument to the selection and creates a derived Text node.|
|`Search Web`|Uses the selected content as a web-search query.|
|`Add Relation`|Creates a Relation between selected nodes using the Relation Editor.|
|`Suggest Relations`|Asks an LLM for Relation candidates, which you can review before applying.|
|`Export`|Saves Text or Artifact as `.md`, or Image as an image file.|
|`Export as Slides (Marp)`|Combines selected Text and Artifact nodes into Marp-format Markdown. If the right-clicked node is not selected, it is added to the export.|
|`Delete Node`|Deletes the target node.|

### 5.2 Right-clicking a Relation

- `Edit Relation`: Change the source, target, type, direction, and reason.
- `Reverse Direction`: Reverse the Relation's direction.
- `Delete Relation`: Delete the Relation.

### 5.3 Right-clicking an Empty Canvas Area

- `Suggest Relations`: Generate Relation candidates from the current scope.
- `Suggest Clusters`: Suggest groups of related nodes as a Generated View.

## 6. Relations and SubCanvases

### 6.1 Relation Editor

Open it with `Add Relation` or `Edit Relation`.

|Item|Description|
|---|---|
|`Source Node`|The starting point of the Relation.|
|`Target Node`|The endpoint of the Relation. It cannot be the same as the source.|
|`Type`|Choose `source`, `derived`, `supports`, `opposes`, or `similar`.|
|`Direction`|Choose forward (source → target) or reverse.|
|`Reason`|Records the rationale or explanation for the Relation.|

### 6.2 Creating a SubCanvas

1. Select one or more nodes on the same Canvas.
2. Right-click a selected node and choose `Create SubCanvas`.
3. Double-click the resulting FolderNode to enter the SubCanvas.
4. Use `Parent` or the breadcrumbs to return to a higher Canvas.

Inside a SubCanvas, right-click selected nodes to move them back to the parent Canvas.

### 6.3 Deleting a SubCanvas

Right-click a FolderNode, choose `Delete SubCanvas`, and confirm the dialog.

- Members of the SubCanvas move to the parent Canvas.
- Relations among members are preserved.
- Relations connected to the FolderNode are deleted.
- The operation can be restored with `Undo`.

## 7. AI Assistant

Switch between `Chat` and `Direct` at the top of the AI Assistant. Selected nodes are passed as context, and the `Context` field shows Text and Image counts.

### 7.1 Chat Mode

Chat mode provides an ongoing conversation with an LLM.

1. Select Canvas nodes as needed.
2. Open `AI Assistant` and select `Chat`.
3. Enter a question or instruction.
4. Click `Send`, or press `Ctrl+Enter` (`Command+Enter` on macOS).
5. Click `Stop` to cancel an operation in progress.

Use the session selector at the top to switch to a previous conversation, or click `New` to create one. If a Canvas change is proposed during a conversation, review the proposal card and apply or reject it. Proposals are never applied automatically.

### 7.2 Direct Mode

Direct mode applies an operation directly to selected Canvas information without using conversation history.

- `Text`: Generates text from the prompt and context and creates a new Text node.
- `Image`: Generates or edits an image from the prompt, selected images, and selected text, then creates a new Image node.
- `Image Provider`: Select OpenRouter, OpenAI, Google, or xAI for that operation.

After entering a prompt, click `Generate`. On completion, the result, created node ID, or differences are shown. You can run `Undo` from a Direct operation's result notification.

### 7.3 Next Step

`Next Step` suggests operations based on the current selection, Canvas, and conversation. Examples include comparisons, counterarguments, web searches, Relation suggestions, Cluster suggestions, and clarifying questions.

Review and edit the proposed target nodes or query before running it. A suggestion may become invalid if it refers to an old selection or Canvas state.

## 8. Web Search

Start a web search by entering a query in the AI Assistant and clicking `Web Search`, or from a node's context menu.

1. Configure a web-search provider and API key in Settings.
2. Enter and run a query.
3. Review the Sources, Claims, and Relation candidates in Projected Context at the top of the screen.
4. Select the Sources, Claims, and Relations you want to keep on the Canvas.
5. Click `Add to Canvas` to promote them.

Search results are temporary review data. They do not become persistent Canvas nodes until you select and add them. Use `Open URL` to inspect a source in an external browser.

## 9. AI Suggestions for Relations and Clusters

### 9.1 Relation Suggestions

Running `Suggest Relations` displays a list of candidates. Review each candidate's source, target, type, and reason; edit it if necessary; then approve it. You can also reject or close the proposal.

### 9.2 Cluster Suggestions and Generated Views

Running `Suggest Clusters` proposes a temporary Generated View with color-coded nodes. After approval, a View banner and Cluster chips appear at the top.

- Click a Cluster name: Rename it.
- `×`: Remove that Cluster from the temporary View.
- `Convert to SubCanvas`: Move the Cluster's members into a persistent SubCanvas.
- `Close View`: End the temporary display without changing the original Canvas document.

The Generated View itself is temporary. The Canvas document changes only when you confirm `Convert to SubCanvas`.

## 10. Settings

After changing settings, click `Save Settings` at the bottom of the drawer.

### 10.1 Language

- `Follow System Settings`
- `日本語`
- `English`

Changing this setting switches the primary GUI, messages, and dialogs to the selected language.

### 10.2 File Operations

- `Save Canvas`: Save the current Workspace to a `.json` file.
- `Open Canvas`: Load a saved `.json` file.

Unsaved edits are lost when the application exits, so explicitly save any work you want to keep.

### 10.3 LLM Settings

|Item|Description|
|---|---|
|`API Base URL`|An OpenAI-compatible API endpoint.|
|`Model`|The model used for text generation, summaries, and Chat.|
|`API Key`|The LLM provider's API key.|
|`System Prompt`|Shared instructions for response language, formatting, and behavior.|

When Image nodes are included in the context, select a model that supports image input.

### 10.4 Image Generation

|Item|Description|
|---|---|
|`Provider`|Choose OpenRouter, OpenAI, Google, or xAI.|
|`Model`|The image-generation model used with the selected provider.|
|`API Key`|The selected provider's API key.|
|`Download Directory`|The storage location for generated and imported images. The default relative path is `Image/`.|

Editing with multiple reference images also depends on support from the selected provider and model.

### 10.5 Web Search

- `Provider`: Select Ollama, Kagi, or Brave.
- `API Key`: Enter the credentials required by the selected provider, such as Kagi or Brave.

### 10.6 Generation Settings

`Maximum Summary Length` sets the maximum length of node summaries.

### 10.7 Destructive Operations

- `Clear Canvas`: Delete nodes and Relations from the current Canvas. You can restore them with `Undo`.
- `New Workspace`: Start a new Workspace and clear the current conversation.

## 11. Importing and Exporting Files

### 11.1 Importing Files onto the Canvas

Drag supported files from the operating system onto the Canvas. A node is created at the drop location.

|Type|Supported extensions|Result|
|---|---|---|
|Text|`.txt`, `.md`|Added as an Artifact node with the original filename preserved.|
|Image|`.png`, `.jpg`, `.jpeg`, `.webp`|Added as an Image node and copied into `Import/` under the image storage directory.|

For an unsupported format, read failure, or copy failure, an error appears at the bottom of the Canvas.

### 11.2 Exporting a Node

Right-click a node and choose `Export`.

- Text: A `.md` file with the summary or configured name suggested as its filename.
- Artifact: A `.md` file with the node's filename suggested.
- Image: Saved in the original image format.

### 11.3 Exporting Marp Slides

Select multiple Text or Artifact nodes, right-click, and choose `Export as Slides (Marp)`. Each node is saved as Marp Markdown separated by `---`. Image nodes are not added to the Marp body.

## 12. Stored Data and Security

### 12.1 Canvas Data

`Save Canvas` stores data in a `.json` file selected by the user. It includes nodes, Relations, the Canvas hierarchy, positions, and related information.

### 12.2 Application Settings

On Windows, settings are normally stored at:

```text
%APPDATA%\fm-doc-canvas\config.json
```

API keys are stored in a local settings file. Do not carelessly share settings files, Canvas files, or logs in public repositories or with third parties.

### 12.3 Chat History

On Windows, chat history is normally stored by Canvas ID at:

```text
%APPDATA%\fm-doc-canvas\chat-sessions.json
```

Even if a Canvas file is saved under a different name, Chat history is managed using its stable Canvas ID. `New Workspace` clears the current conversation.

### 12.4 Image Files

Generated images are stored in the configured `Download Directory`. Imported images are copied into its `Import/` subdirectory. Moving only the Canvas JSON to another computer may break image references, so manage the image directory together with it.

## 14. Troubleshooting

### AI Operation Buttons Are Disabled

- Make sure the input field is not empty.
- Check the API Base URL, model, and API key in Settings.
- Check whether another AI or web-search operation is in progress.
- Wait for Chat history to finish loading.

### An Image Cannot Be Sent to the AI

- Select the Image node before opening the AI Assistant.
- Check the Image count under `Context`.
- Use an LLM or image model that supports image input.
- Confirm that the image file exists in the configured image storage directory.

### Web Search Fails

- Check the web-search provider and API key.
- Make sure the query is not empty.
- Select `Open Settings` from the Projected Context error and reconfigure it.

### A Proposal Cannot Be Applied or Is Marked Invalid

If nodes, Relations, the Canvas, or the selection changes while an AI operation is running, the proposal may become stale (invalid) to prevent an old result from being applied incorrectly. Select the current targets and run it again.

### Images Are Missing after Opening a Canvas

Canvas JSON does not always embed the image data itself. Restore the original image storage directory and its `Import/` folder, and confirm that `Download Directory` is configured correctly.

## 15. Basic Workflow Examples

### Turn Research Results into an Artifact

1. Configure an LLM and web search in Settings.
2. Write a topic or search term in a Text node.
3. Select the node and run `Search Web`.
4. Select the desired Sources and Claims in Projected Context and add them to the Canvas.
5. Select multiple related nodes and run `Summarize` or `Compare`.
6. Convert the result node to an Artifact and finish it in Edit and Preview.
7. Right-click and choose `Export` to save the Markdown.

### Create Image Variations from a Reference

1. Drop a `.png`, `.jpg`, `.jpeg`, or `.webp` file onto the Canvas.
2. Select the reference Image node and, if needed, a Text node containing instructions.
3. In the AI Assistant, choose `Direct` → `Image`.
4. Enter the desired changes, choose an image provider, and click `Generate`.
5. Review the new Image node and use `Undo` or regenerate if necessary.
6. Right-click the finished image and export it.
