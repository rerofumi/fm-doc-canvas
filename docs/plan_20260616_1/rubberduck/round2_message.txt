質問への回答です。

1. プロンプトがめっちゃ長い場合:
- カード全体を大きくしないために、カード下表示は 3 行程度で省略する方針です。
- スクロールは今のところ導入しません。
- 将来的に全文確認が必要なら、別 UI や詳細表示を考える可能性はあります。

2. ノードの高さが変わってレイアウトがずれるか:
- 既存のノードで `originalPrompt` や `prompt` がない場合は表示を出さないので、既存表示はなるべく変えません。
- 新規生成ノードではカード内に footer 領域を確保して、本文や画像表示領域を少し狭める方向です。
- ノードの外寸を自動で大きくして周囲レイアウトを押し広げるのは避けたいです。

3. ズーム範囲を広げたことをユーザーが気づけるか:
- React Flow のズームコントロールとホイール操作が新しい `minZoom` / `maxZoom` に従うことを期待しています。
- 追加の UI は今のところ作りません。
- 操作してみて範囲が足りないようなら、後でズーム設定 UI を検討する可能性があります。

次のラバーダックの質問を 1〜3 個だけしてください。技術提案や実装計画ではなく、質問だけにしてください。
