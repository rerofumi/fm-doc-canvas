最後の質問への回答です。

1. React Flow のデフォルトズームコントロール:
- `minZoom` / `maxZoom` を ReactFlow に渡すことで、ホイール操作だけでなくデフォルトの +/- ボタンもその範囲を尊重する想定です。
- ただし実装後に手動確認して、ボタンが範囲外へ移動しないことは確認します。

2. CustomNode と ImageNode の表示実装がバラバラになるか:
- 今回の MVP では、カード下表示の共通コンポーネント化までは行わない方針です。
- ただし、表示ロジックが似てくるので、将来的には `PromptCaption` のような共通パーツに抽出する余地があります。

3. 古いバージョンの Wails アプリで新しいフィールドを無視できるか:
- 既存の `CanvasFileV1_1` のノード data 内に任意項目を追加するだけなので、古いアプリでも JSON パース上は問題ない想定です。
- 古いアプリは `originalPrompt` / `prompt` を表示しないだけで、既存の `content` / `summary` / `src` / `alt` は維持されます。
- ただし古いアプリで保存し直すと、未認識の任意項目が消える可能性はあるため、バージョン間を行き来する運用では注意が必要です。

以上で 3 往復の回答を終了します。
