# App Requirements

## Purpose

AI 生成ノードの運用を整理し、生成元プロンプトをノードとしてではなくカード内の簡易情報として扱えるようにする。これによりキャンバスのノード数を増やさず、生成内容と元の質問を同じ場所で確認できる。

## Target Environment

- Wails アプリケーション
- Frontend: React + TypeScript + Zustand + Tailwind CSS
- Canvas: `@xyflow/react` 12.x
- Backend: 変更なし

## User Experience

### 画像生成

- ユーザーが Image モードでプロンプトを送信すると、画像ノードのみが作成される。
- 画像ノードのカード下に、画像生成に使ったプロンプトが簡易表示される。
- プロンプトノードは作成されないため、キャンバス上に不要なテキストノードが増えない。

### テキスト生成

- ユーザーが Text モードで質問を送信すると、回答ノードが作成される。
- 回答ノードのカード下に、元の質問プロンプトが簡易表示される。
- 回答本文・サマリーとは別に、質問プロンプトを参照できる。

### キャンバスズーム

- 拡大方向にも縮小方向にも、現在より広いズーム範囲で操作できる。
- React Flow のズームコントロールやホイール操作が新しい範囲に従う。

## MVP Features

- `PromptBar` が画像生成時にプロンプトノードを作成しない
- `PromptBar` が生成ノードの data に元の質問プロンプトを保存する
- `CustomNode` が `originalPrompt` を持つ場合にカード下に簡易表示する
- `ImageNode` が `prompt` を持つ場合にカード下に簡易表示する
- `CanvasArea` のズーム範囲を拡大・縮小ともに拡張する

## Future Candidates

- 簡易プロンプト表示の行数やラベル文言をユーザー設定化する
- カード下プロンプトを編集可能にする
- 生成元プロンプトを履歴として複数保持する
- ズーム範囲をユーザー設定化する

## Initial Non-Goals

- バックエンド API の変更
- キャンバス JSON のバージョン番号更新
- 既存ノードの一括マイグレーション
- 画像生成 API の挙動変更
- 画像生成 API プロバイダの追加・修正
