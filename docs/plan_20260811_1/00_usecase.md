# 思考整理ツール振り返り   
## 自作ツール群   
fm-live-radio   
  [http://192.168.0.120:33000/rerofumi/fm-live-radio](http://192.168.0.120:33000/rerofumi/fm-live-radio)    
  AI音楽生成モデルによる無限生成BGMと時たま挟まるニュースアナウンス   
  作業中 BGM として良く使う、ニュースは RSS 由来だが既知の情報、新しい情報が適度に混ざっていて必ずしも必聴でないところが逆に心地よい   
fm-mindmap   
  [http://192.168.0.120:33000/rerofumi/fm-mindmap](http://192.168.0.120:33000/rerofumi/fm-mindmap)    
  自分で使う小規模マインドマップと LLM Chat を組み合わせた画期的な思考ツール   
  ナイスな物ができたと大喜びしたが、マインドマップ入力が割と面倒に感じるのであまり使っていない、もうひと磨きしたい   
fm-doc-canvas   
  [http://192.168.0.120:33000/rerofumi/fm-doc-canvas](http://192.168.0.120:33000/rerofumi/fm-doc-canvas)    
  LLM へのプロンプトと回答を 1カードとしてキャンバスに記録していくタイプの思考ツール。カードを選択したりノードとして接続したりして後からコンテキストとして構成できるのが特徴。   
  作ったツールの中では良く使っている。ただしテキスト情報ツールとしてでは無く、画像生成＆参照画像生成がやりやすくてそればっかやっている。画像的情報整理にはなっているかも。   
  テキストベースの情報構築もやりやすくはあるんだけれども、やっぱり課題は検索、調査、質問から始まることが多いのでいきなりこのアプリを開こうとならないあたりが課題。   
fm-memo-chunk   
  [http://192.168.0.120:33000/rerofumi/fm-memo-chunk](http://192.168.0.120:33000/rerofumi/fm-memo-chunk)    
  MCP で読み書きできる、お気軽テキストメモ。   
  なんか雑多なメモを放り込んで LLM エージェントで整理、他のメモアプリに移動ということを考えていたけれども、どのタイミングで整理すべきか、残したいメモは何かを考えるのが面倒で結局使わない形に。   
fm-link-stash   
  [http://192.168.0.120:33000/rerofumi/fm-link-stash](http://192.168.0.120:33000/rerofumi/fm-link-stash)    
  URL メモとしてとにかく気になったページを方折り込んでおく形のブックマークアプリ。MCP  サーバー機能があり LLM エージェントからも閲覧、利用ができる。   
  URL の取りあえずメモ先として便利で良く使ってはいる。   
  貯めた過去の情報にどうアクセスするか、古い情報へのアクセスで使いやすい UI を持たせることが課題。あと MCP 機能をあんま使ったことが無い。   
fm-image-assistant   
  [http://192.168.0.120:33000/rerofumi/fm-link-stash](http://192.168.0.120:33000/rerofumi/fm-link-stash)    
  今製作途中のアプリ。ComfyUI での画像生成を行うため、ローカル LLM エージェントでプロンプトを作成したり、生成結果を VLLM で caption して意図通りの生成ができているかを確認したりするインテリジェントなアプリ。エージェント機能でユーザーが意図した画像になるまでループを回すという機能が特徴。   
  自分で使う道具としてかなり満足度が高く、よく利用している。   
fm-image-prompt-manager   
  [http://192.168.0.120:33000/rerofumi/fm-image-prompt-manager](http://192.168.0.120:33000/rerofumi/fm-image-prompt-manager)    
  画像生成で良く使うプロンプトやキャラクターを DB に登録、管理してそれらを組み合わせた画像を容易に生成するためのアプリ。   
  プロンプトの登録、登録されたプロンプトの検索が面倒で、テキストファイルで直に取り回す方が楽なので使わないでいる。   
     
## LLMチャット   
kagi assistant   
  使える LLM は 2軍クラスだが、kagi の持つ検索機能を存分に使ってくれるので調査検索のメインとして使い続けている。正直今の LLM は高性能で思考と言語は十分で、強力な検索で知識を補ってくれればそれで良いと思っている。   
gemini   
  相談相手として良く使っていたが、検索を確実に行ってくれるという保証に薄く使う機会が減っていった。   
hermes agent - kurumi   
  知識は検索で補うというポリシーのもと作った grouding, ollama search skill が強力で調査分析はお任せ状態となっている。   
ChatWize   
  OpenRouter の幅広いモデルを使うために昔は主力だったが、日常的な質問を投げる用途としては知識検索部分が薄かったので使わなくなりつつある。
