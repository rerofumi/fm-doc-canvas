## 不具合レポート

### markdown view からの URL リンク

Node Edit の Preview mode、および Artifact Node のコンテンツ表示にて URL があった場合リンク扱いになるが、クリックすると Wails の WebView 内でその URL に遷移してしまい、アプリから離れてしまう。また、アプリに戻ることもできなくなる。
markdown view の URL リンクは別アプリで開き、OS 標準設定のブラウザで開くことが期待値。

### chat ペインでのコンテキスト

chat は一見会話できている様に見えるけれども、過去の発言をコンテキストとして持っていない。
「さっきの情報を纏めて Text Node として Canvas に張って」や「ここまでの会話を纏めて」と指示しても『会話がありません』と返ってきて期待通りの機能にならない。
