# Claim

## Purpose

`fm-doc-canvas` は、テキストと画像をノードとして無限キャンバス上に配置し、ノード間の接続を文脈として LLM や画像生成 API に渡せる AI メモツールである。

## Background

実装は Wails v2 を基盤にしたデスクトップアプリケーションで、Go バックエンドと React フロントエンドで構成される。フロントエンドは React Flow を使ってノードとエッジを表示し、Zustand でキャンバス状態と設定を管理する。

## Problem

単発のチャットやメモでは、思考の分岐、参照関係、生成結果の蓄積を視覚的に扱いにくい。このアプリは、ノードの接続関係を使って前提文脈を明示しながら、テキスト生成、画像生成、画像参照付き生成をキャンバス上で継続できるようにする。

## Target Users / Environment

- Wails が動作するデスクトップ環境で、ローカルファイルと外部生成 API を使ってドキュメントやアイデアを整理する利用者。
- OpenAI 互換 API、OpenRouter、OpenAI Images/Responses API、Google Generative Language API、xAI 画像 API のいずれかを設定できる利用者。
- 開発時のツールチェーンは `mise.toml` に従い、Go、Node.js、Wails CLI を `mise` 経由で扱う。

## Current Scope

- テキストノードと画像ノードの作成、表示、リサイズ、削除。
- ノード間エッジによる文脈トラバース。
- テキスト生成、要約生成、画像生成、画像参照付き生成。
- `.json` キャンバスファイルの保存と読込。
- テキスト/画像ファイルのドラッグアンドドロップインポート。
- Markdown、画像、Marp 形式 Markdown のエクスポート。
- ローカル設定ファイルへの API 設定保存。

## Assumptions

- API キーはローカル設定ファイルに平文保存される。
- キャンバス内容は自動保存されず、ユーザーが明示的に保存した JSON ファイルにのみ永続化される。
- 画像ファイルは設定された画像保存先ディレクトリを基準に管理される。
