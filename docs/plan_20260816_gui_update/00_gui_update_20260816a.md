# fm-doc-canvas GUI update

機能面はできるだけ触らず、GUI 関連の改善のみ行うのが今回の目的。

## 全体

problem: 日本語と英語が混在
GUI に表示するテキストを i18n 化、メッセージテーブルにする

## 機能不具合

problem: SubCanvas の名前を変更することができない

problem: SubCanvas 内のノードを他の Canvas に移動できない

problem: SubCanvas を削除できない
SubCanvas 内が空ならそのまま削除、ノードがあったら parent に移動したあと SubCanvas を削除

problem: Node 選択/フォーカスしたあと、フォーカスリストのチェックボックスから除外してもアイテムのフォーカスが消えない。その後フォーカスを解除して再選択しても一度除外したアイテムは二度とフォーカスリストに現れない
フォーカスアイテム数の表示は欲しいが、リスト表示と除外チェックボックスは不要な機能

## メイン画面

problem: 右上のアイコンボタンが無秩序＆整理したい

problem: New Workspace ボタンは config 内の Clear Canvas と同機能。Danger 扱いなので Config の奥深くでよく、トップに存在していなくても良い

problem: Load/Save は Config 内にあるのでトップに存在していなくても良し

problem: Undo, Chat ボタンも Icon+Text にして欲しい

problem: Use this Canvas as context ボタンは不要では？

## ノード詳細＆テキスト編集ドロワー

特に不満無し、現状で良い

## チャットドロワー

problem: チャットを行ってもセッション名が『会話なし』のまま、セッションが増えても同じ名前なので区別が付かない

problem: Chat と Direct の 2つ入力欄があるのはやはり UX として良くない Direct ペインを削除し、Chat ドロワーに "Chat / Direct Prempt" 2つのタブを作り入力テキストボックスは共通で使うとした方が良い

problem: 次の一手ボタンが半端な位置
送信ボタンの列、左側に配置するのが良さそう
「次の一手」 「Web検索」「送信」とボタンをここに並べる
